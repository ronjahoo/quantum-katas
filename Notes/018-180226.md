# Continued Linear Algebra Section

Exercise 9
- Easy task, adjoint function was ready and just needed to write down the 1xn/nx1 inner product algorithm which is straight forward

```
@exercise
def inner_prod(v : Matrix, w : Matrix) -> complex:
    a = adjoint(v)
    total = 0
    for i in range(len(w)):
        total += a[0][i] * w[i][0]
    return total
```
