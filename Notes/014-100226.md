- Easy task, just to change columns to rows

```
@exercise
def transpose(a : Matrix) -> Matrix:
    c = create_empty_matrix(len(a[0]), len(a))
    for i in range(len(a[0])):
        for j in range(len(c[0])):
            c[i][j] = a[j][i]
    return c
```
