# Continued Complex Arithmetic

Exercise 8
- took a while to remember the rules for exponents etc. but then the calculation opened easily

```
@exercise
def complex_exp_real(r : float, x : Complex) -> Complex:
    if (r == 0): return (0,0)
    
    (a, b) = x
    ra = r ** a
    lnr = math.log(r)
    
    real = ra * math.cos(b * lnr)
    imaginary = ra * math.sin(b * lnr)
    
    return (real, imaginary)
```
