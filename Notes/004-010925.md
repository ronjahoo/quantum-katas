# Continued Complex Arithmetic

Exercise 6
- very easy math problem

```
@exercise
def modulus(x : Complex) -> float:
    return math.sqrt(x[0] ** 2 + x[1] ** 2)
```

- required a bit more writing on paper with the equations but I found the result quite easily

```
@exercise
def complex_exp(x : Complex) -> Complex:
    g = math.e ** x[0] * math.cos(x[1])
    h = math.e ** x[0] * math.sin(x[1])
    return (g, h)
```
