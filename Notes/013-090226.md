- Quite easy task because the function plays only with 2x2 matrices.

```
@exercise
def matrix_inverse(a : Matrix) -> Matrix:
    c = create_empty_matrix(2,2)
    det = a[0][0]*a[1][1] - a[0][1]*a[1][0]

    c[0][0] = a[1][1] / det
    c[1][1] = a[0][0] / det
    c[1][0] = -1 * a[1][0] / det 
    c[0][1] = -1 * a[0][1] / det
    return c
```
